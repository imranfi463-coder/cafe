# Cafe Website

A responsive cafe website for **Cafe** in **Soorangal, Kinniya**.

## Features

- Light brown and white theme
- Responsive layout for desktop, tablet, and mobile
- Menu section with prices
- Real cafe-style images
- Location section with Google Maps link and embedded map
- Visit section with address and opening hours

## Project Files

- `index.html` - main website structure
- `styles.css` - design, colors, layout, and responsive styles
- `script.js` - mobile navigation behavior

## Run Locally

Open `index.html` in your browser.

## Deployment

This repository includes a GitHub Actions workflow to deploy the site with GitHub Pages.

After pushing to the `main` branch:

1. Open your GitHub repository.
2. Go to `Settings > Pages`.
3. If needed, set the source to `GitHub Actions`.
4. Wait for the workflow to finish.

Your site URL will usually be:

`https://imranfi463-coder.github.io/cafe/`
